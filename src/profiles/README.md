# 거래소 프로필

소명할 때 **어디에, 무엇을, 언제까지** 내는지를 거래소별로 정리합니다.

`src/server/exchanges/`(입금 목록 불러오기)와는 다른 일입니다. 여기는 API 연결이 아니라 공개 자료를 정리한 데이터입니다.

## 구조

| 파일 | 내용 | 담당 |
|---|---|---|
| `groups.ts` | 국내 · 해외 공통 칸 (적용 법, 문서 언어, 기본 요청 자료) | 리서치 확인 후 수정 |
| `exchanges/upbit.ts` 등 | 거래소별 칸 (제출 창구, 요청 자료, 심사 기간) | 거래소 프로필 · 국내 / 해외 |
| `registry.ts` | 거래소 목록과 화면 순서 | 거래소를 추가할 때만 |
| `route.ts` | 제한 유형 + 프로필 + 기준일 → 제출처와 기한 | 리포트·통합 |
| `__tests__/route.test.ts` | 기한 계산, 출처 누락 검사 | 같이 |

| 구분 | 거래소 | 상태 |
|---|---|---|
| 국내 원화 거래소 | 업비트 | 확인 완료 (일부 칸은 확인 필요) |
| | 빗썸, 코인원, 코빗, 고팍스 | 리서치 중 |
| 해외 거래소 | Kraken | 확인 완료 |
| | Coinbase, Binance | 리서치 중 |

리서치 중인 거래소는 거래소별 칸을 "리서치 필요"로 두고, 요청 자료와 안내는 공통 칸을 씁니다.

## 프로필 채우는 법

1. `exchanges/거래소.ts`의 `researchProfile(...)` 한 줄을 아래 모양으로 바꿉니다.
2. 공개 문서에서 확인한 칸만 `status: "verified"`로 쓰고, 출처를 꼭 붙입니다. 출처가 없으면 테스트가 실패합니다.
3. 찾지 못한 칸은 지우지 말고 `status: "check"`로 남깁니다.
4. `status`를 `"verified"`로, `checkedAt`을 확인한 날로 바꿉니다.
5. `npm test`로 확인합니다.

```ts
import type { ExchangeProfile } from "@/types/case";

export const bithumb: ExchangeProfile = {
  id: "bithumb",
  name: "빗썸",
  group: "kr",
  status: "verified",
  language: "ko",
  channel: "공개 문서에 적힌 제출 창구",
  reviewPeriod: null, // 안내된 심사 기간이 있으면 문자열로. 제출 기한과 다릅니다
  requestedDocuments: ["txHash", "depositReason", "bankRecords"], // documents.ts의 키
  fields: [
    {
      label: "요청 자료",
      value: "공개 문서 문구를 거의 그대로 옮깁니다",
      status: "verified",
      source: { label: "문서 이름", url: "https://..." },
    },
    { label: "심사 기간", value: "공개 자료에서 찾지 못했습니다.", status: "check" },
  ],
  checkedAt: "2026-11-05",
};
```

## 지킬 것

| 규칙 | 이유 |
|---|---|
| 공개 문서로 확인한 내용만 `verified`로 쓰기 | 추측이 섞이면 소명서 전체를 믿을 수 없게 됨 |
| 문서 문구를 바꿔 쓰지 말고 거의 그대로 옮기기 | 거래소 담당자가 원문과 대조할 수 있게 |
| 거래소 로고나 공식 양식처럼 보이는 표현 쓰지 않기 | 비공식 정리 도구 |
| `groups.ts`의 법 조항 요약은 리서치 담당 확인 후 고치기 | 모든 거래소 안내에 영향 |
| 화면 문장은 [문장 규칙](../../docs/writing-rules.md) 따르기 | |

## 기한 계산

`route.ts`가 계산합니다.

| 제한 유형 | 기준일 | 기한 |
|---|---|---|
| 거래소 내부 심사 | 거래소 통지에 적힌 제출 기한 | 그 날짜까지 |
| 보이스피싱 법정 지급정지 (국내) | 채권소멸절차 개시 공고일 | 공고일부터 2개월 (민법 기간 계산으로 추정) |
| 제재에 따른 동결 | 없음 | 해당 절차에서 확인 |
| 아직 모름 | 없음 | 제한 유형부터 확인 |

보이스피싱 기한은 추정입니다. 마지막 날이 토요일이나 공휴일이면 늘어날 수 있어서, 화면에 "공고문에서 확인"을 같이 보여줍니다.
