# 원치 않은 입금 소명 지원 도구

사용자가 요청하지 않은 의심 입금을 받았을 때, 거래소에 제출할 소명 자료를 준비하도록 돕는 Next.js 프론트엔드 목업입니다.

단순한 발표용 HTML이 아니라 실제 백엔드 API를 연결할 수 있도록 화면, 데이터 타입, API 계층을 분리했습니다.

## 현재 구현

1. 요청 확인 — 거래소와 받은 소명 요청 유형 확인
2. 거래 선택 — 공개 지갑 주소로 최근 수신 거래 조회 및 문제 거래 선택
3. 온체인 조사 — 발신 관계, 유사 송금 패턴, 입금 이후 행동 확인
4. 진술 검토 — 사용자의 설명과 증빙 자료 입력
5. 자료 생성 — 온체인 사실과 사용자 진술을 구분한 제출 자료 미리보기

현재는 결정적인 목업 데이터를 사용하며, 파일 첨부는 파일명·형식·크기만 브라우저 상태에 보관합니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다.

## 검증

```bash
npm run typecheck
npm run build
```

## 백엔드 연동

`.env.example`을 참고해 `NEXT_PUBLIC_API_BASE_URL`을 설정합니다.

```bash
NEXT_PUBLIC_API_BASE_URL=https://api.example.com
```

화면은 `src/lib/api/cases.ts`를 통해서만 데이터를 요청합니다. 실제 API가 준비되면 이 파일의 요청 구현과 응답 타입을 맞추는 방식으로 연결할 수 있습니다.

실제 파일 업로드 연동 시에는 원본 파일을 업로드 API로 전송하고, 보고서 생성 요청에는 반환된 파일 ID를 포함하는 구조를 권장합니다.

## 주요 구조

```text
src/
├── app/                    # Next.js 화면과 전역 스타일
├── features/case/          # 5단계 사용자 흐름과 조사 그래프
├── lib/api/                # 백엔드 API 연결 지점
├── mocks/                  # 개발용 목업 데이터
└── types/                  # 요청·응답 데이터 타입
```

## 범위

- 이 도구는 사실과 정황을 정리하는 보조 도구입니다.
- 특정 주소의 범죄 연루나 법적 책임을 확정하지 않습니다.
- 실제 거래 조회, 파일 업로드, PDF 생성은 백엔드 연동 전까지 목업으로 동작합니다.
